# Root Level CLAUDE.md Guide

## Purpose
Document the overall project structure, purpose, and high-level architecture at the root level.

## Contents

### Project Overview
- Brief description of the app/project
- Tech stack (e.g., SwiftUI, iOS version, dependencies)
- Main purpose and use case

### High-Level Structure
- Key folders and their purposes
- Build configuration (if relevant)
- Entry points

### Important Notes
- Any setup requirements
- Key patterns or conventions used
- Links to detailed guides if they exist

## Template

```markdown
# slapme

[One-line project description]

## Stack
- **Framework**: [e.g., SwiftUI]
- **Platform**: [e.g., iOS 17+]
- **Language**: Swift

## Project Structure
- `slapme/` — Main app source code
- `slapme.xcodeproj/` — Xcode project configuration

## Key Features
- [Feature 1]
- [Feature 2]

## Getting Started
[Brief setup instructions if needed]
```

## Length Guidelines
- 50-100 lines max
- Keep under 300 total characters including code
- Focus on navigating the codebase, not exhaustive documentation
